## 🚀 Getting Started

```bash
# Clone the repository
git clone git@github.com:rubenmtzb/rubenmtzb.github.io.git
cd rubenmtzb.github.io

# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```
